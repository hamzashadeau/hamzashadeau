# 💫 About Me:
Ingénieur développeur Java / Python avec 4 ans d'expérience, spécialisé dans la conception d'APIs sécurisées à fort trafic (plus de 50 000 utilisateurs) et l'architecture microservices.<br><br>J'apporte une expérience complémentaire en data science — modèles prédictifs, pipelines ETL — et en intégration d'agents IA pour l'automatisation de processus métier. Concrètement : sécuriser une API avec OAuth2 et Keycloak, faire dialoguer des services via Kafka et OpenFeign, industrialiser un déploiement sur Kubernetes, puis brancher un modèle Python de prévision sur les mêmes données.<br><br>Je travaille en Agile / Scrum, avec revues de code quotidiennes, tests unitaires (JUnit, pytest) et logging centralisé sur la stack ELK.
